# Seminar folder (internal planning)

Files in this folder support **coordinator planning** (topic preferences, series design, spreadsheets). They are **not** used to build the public seminar calendar.

## Public seminar listings

Published events for students are maintained in:

**[`_data/seminars.yml`](../_data/seminars.yml)**

See [`AGENTS.md`](../AGENTS.md) for field definitions and copy-paste templates (thesis announcements, GRS seminars, etc.).

The live calendar is deployed to:
<https://ht-timchen.github.io/Adelaide-CSIT-GRC/seminars>
